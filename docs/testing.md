# Проверки

## Быстрый запуск

После подготовки runtime и сборки:

```sh
make test
```

Команда запускает Go-тесты с race detector, интеграционные тесты Qt, проверки инструментов выпуска и криптографическую проверку компактного VK Initial. GUI-тесты используют автономный демон с временным состоянием, без регистрации WARP и изменений сетевой конфигурации.

## Пакетные тесты

```sh
sudo bash scripts/test-netns.sh
```

Скрипт создаёт отдельный network namespace и отказывается выполнять тесты в исходном namespace. Проверяются:

- реальные TLS-разбиения и QUIC-фейки;
- VK-пакеты при MTU 1280 и 1500, сохранность исходной датаграммы;
- VLESS, Trojan, Hysteria2 и Salamander через реальные локальные клиенты и серверы;
- ограничение перехвата по cgroup и сохранение маршрутных меток;
- блокировка при остановке nfqws2 и восстановление собственных правил;
- IP-фрагменты при модели firewall WARP, без разрешения обычного трафика;
- ожидание готовности firewall до обработки очереди;
- загрузки через защищённый транспорт после двух ошибок обычного HTTPS.

Для runtime установленного пакета:

```sh
sudo env ZARP_TEST_RUNTIME=/usr/lib/zarp/runtime bash scripts/test-netns.sh
```

## Проверка установленного пакета

CI использует отдельного обычного пользователя для Qt:

```sh
sudo python3 tools/test-linux.py --installed --gui-user zarpbuild --output build/test-results/local
```

Пользователь должен уже существовать. В CI его создаёт bootstrap-скрипт. Проверка не стартует службу WARP и не подключает действующий туннель. Все результаты сохраняются в JSON, отдельные журналы и `summary.md`; остальные проверки продолжаются после отдельной ошибки.

Для проверки исходников без пакетных тестов:

```sh
python3 tools/test-linux.py --skip-netns
```

## Снимки интерфейса

```sh
python3 tools/preview-ui.py
```

Скрипт снимает окна и анимации в деморежиме. Изображения появляются в `build/preview-linux/`, кадры анимации в `build/animation-frames/`. Снимки не являются доказательством работоспособности стратегии у провайдера.

## Дополнительные проверенные снимки upstream

Тесты реальных внешних архивов включаются явно и не зависят от содержимого локальной `.work/`:

- `ZARP_TEST_UPDATE_ARCHIVE`: архив zapret2 v1.0.6 с ожидаемым SHA-256, для проверки staging и активации обновления;
- `ZARP_TEST_WARP_FIXTURE`: каталог `Release`, `Packages` и `warp.deb`, ранее проверенных по подписанному индексу Cloudflare.

При отсутствии этих необязательных файлов соответствующие тесты пропускаются. Локальные тесты парсеров, недоверенных архивов, хешей и безопасной регистрации выполняются независимо от них.

## Проверка на сети провайдера

Подключение официального WARP, регистрация нового устройства и работа с удалённым сервером выполняются отдельно. Для приёмки запустите быстрый и полный поиск до главной кнопки, отмените подготовку и работающий поиск, повторите подключение, переключите стратегию и проверьте HTTPS через туннель.

Количество рабочих профилей не определяется локальными тестами. Только реальный поиск на нужной сети может подтвердить результат.
