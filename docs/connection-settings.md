# Настройки подключения

## Cloudflare WARP

В **Настройки → Сервер и эндпоинты** выберите WARP. Используется официальный `warp-cli`; собственная реализация WARP и подключение без zapret2 не добавляются.

- **HTTP/3** использует QUIC-стратегии.
- **HTTP/2** использует TLS-стратегии и отдельные TCP-входы MASQUE.
- При первом запуске Zarp ждёт готовности локальной службы, затем читает состояние регистрации. Ошибка IPC не считается отсутствующим аккаунтом.
- Новое устройство регистрируется только через защищённую TLS-стратегию. Неопределённый ответ сохраняется для проверки, а не приводит к повторному созданию аккаунта.

Можно задать список `IP:порт`. При пустом списке используются автоматические значения. Включённый параметр **«Другой эндпоинт при перепроверке»** позволяет отличить два независимых подтверждения от двух проверок одного сервера.

### WARP+

Откройте раздел WARP+ в настройках сервера, введите существующую лицензию и примените её. Запрос проходит через zapret2; официальный клиент сохраняет учётные данные. После смены лицензии переподключитесь.

## Собственный сервер

Включите использование своего сервера и добавьте ссылку или HTTPS-подписку.

| Протокол | Транспорт и обработчик |
| --- | --- |
| VLESS | TLS / Reality, TCP, WebSocket, gRPC, HTTPUpgrade; sing-box |
| Trojan | TLS, поддерживаемые потоковые транспорты; sing-box |
| Hysteria2 | QUIC, в том числе Salamander; sing-box |
| VLESS XHTTP | Xray через локальный аутентифицированный SOCKS-мост к sing-box |

Внешнее соединение выбранного сервера ограничивается его адресом, портом и подходящей стратегией zapret2. Zarp проверяет пару «сервер + стратегия», затем запускает TUN с выбранной маршрутизацией.

Salamander требует UDP-стратегии для непрозрачного трафика. Профиль, ожидающий видимый QUIC Initial, не подходит для уже обфусцированного пакета. Неподдерживаемые комбинации настроек отклоняются до подключения.

## Маршрутизация и программы

Для собственного сервера доступны Direct, Proxy и Block, пользовательские правила доменов и IP, GeoIP/GeoSite и пресеты локальных сетей, России, Ирана и Китая. Для внешних баз используются проверка и атомарная замена загруженных файлов.

Раздел **«Прокси для программ»** позволяет выбрать приложения для TUN. Режим WARP остаётся системным туннелем официального клиента; настройки собственного сервера к нему не применяются.

## Свои стратегии

Формат строки:

```text
# name | transport | arguments | countries (optional)
My QUIC | h3 | --payload=quic_initial --lua-desync=fake:blob=quic_google:repeats=8 | ru
My TLS | h2 | --payload=tls_client_hello --lua-desync=multisplit:pos=1,sld | ru,ir,cn
```

Синтаксис параметров описан в [руководстве zapret2](https://github.com/bol-van/zapret2/blob/master/docs/manual.en.md). Zarp принимает ограниченный набор пакетных параметров; произвольное выполнение Lua или команд оболочки через профиль не разрешается.

## Ошибки

- **MTU:** Zarp подбирает компактный VK Initial на малом канале. Произвольный слишком большой UDP-фейк всё равно может не поместиться.
- **Firewall:** для IP-фрагментов официального WARP добавляется только временное правило уже обработанных пакетов к выбранному серверу. Оно удаляется при отключении и восстановлении после сбоя.
- **Нет подключения:** не всякая стратегия работает в любой сети. Увеличьте ожидание при медленном установлении соединения и выполните полный поиск.
- **Не прошла проверка HTTPS:** статус WARP не подтвердился реальным трафиком. Такой результат не считается рабочим.

Текст результата доступен полностью во всплывающей подсказке. Журнал и диагностика помогают отличить ошибку клиента, стратегии и проверки трафика.
